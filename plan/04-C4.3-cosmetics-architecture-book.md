# C4.3 — Cosmetics, equipment và Architecture Book

Trạng thái: Planned. Dependency: C4.2 + approved art. GDD: 39, 41A–41S, 68. Art spec: [file 12](12-art-requirements.md).

## 1. Launch content và fairness

Default + Classic Brick đầy đủ trên hai nền tảng nếu đạt budget. Brick gồm 12 stack modules, bốn minis, crane/hook và collection badge. Roof equipment dùng bốn roof modules của bộ, không yêu cầu gen thêm bộ mái thứ hai.

Không Modern Glass/Neon/premium rarity/shop trong phase này. Trang bị chỉ thay hình, không đổi geometry, rope curve, offset thả, opacity có lợi, chất lượng, population hoặc speed. Default tiếp tục usable miễn phí.

## 2. Catalog và save

- [ ] Cosmetic catalog versioned: ID ổn định, category (`building`, `roof`, `crane`, `badge`), class compatibility, set ID, asset IDs, unlock rule, EN/VI labels, availability.
- [ ] Inventory ownership lưu theo item IDs; equipment có building/roof theo từng class và crane chung.
- [ ] Sửa CityBuilding skin union thành catalog ID validated; validator không reset valid inventory về default.
- [ ] Gộp inventory về nguồn duy nhất ở GameSave; legacy City inventory migrate, không giữ hai kho ownership có thể lệch.
- [ ] Unknown/unavailable asset fallback default khi render nhưng không xóa ownership. Invalid item ID không được equip.
- [ ] City building snapshot lưu building skin/roof skin; active run pin equipment từ lúc start. Resume không lấy trang bị mới.
- [ ] Equip item owned; preview locked có watermark/nhãn locked trong UI, không ghi vào save equipment.
- [ ] Tower hiện có chỉ đổi bằng rebuild trong bản đầu; không tự thay cả skyline khi equip.

Default unlock rules: 20 completed towers/class mở Brick building class; 50 Perfect body/class mở Brick roof; bảy credited Daily dates mở Brick crane; sở hữu tất cả building/roof/crane mở badge. Default roof vẫn dùng được khi Brick building unlocked nhưng Brick roof chưa unlocked. Completion/Perfect predicates dùng C4.2 counters, không cộng lại lúc mở Book.

Assets chưa approved thì item không earnable trong release; không quảng cáo reward bị thiếu. Khi bật catalog sau này, evaluate lifetime milestones một lần và cấp reward tương ứng cho người đã đạt, qua receipt có item ID/version.

## 3. Art import và rendering

- [ ] Chạy quy trình source → QA → approved → export hai target → manifest/crop update.
- [ ] Importer mới nhận revision v001/v003 và subfolder; không chạy script v001 hiện có để vô tình ghi đè compact/new art.
- [ ] `sprites.ts` resolve asset theo class + part + equipment; crop/anchor nằm trong metadata, không đo alpha mỗi frame.
- [ ] Decode/pre-rasterize theme trước khi start hoặc equip preview; không đổi texture trong swing/drop.
- [ ] Lazy-load Brick khi mở preview hoặc trước start với Brick; cache bounded, resize rebuild cache có kiểm soát.
- [ ] City minis dùng skin đã snapshot; default fallback rõ ràng nếu optional theme load fail.
- [ ] Independent crane skin giữ pivot/hook attachment hiện tại; không thay rope length bằng kích thước PNG.

## 4. Architecture Book / customization UX

Book có tabs bốn class và set collection. Class page: tên, body target 10/20/30/40, adjacency, mastery, owned/locked building/roof, unlock progress. Set page: các item và completion badge.

Customization flow: chọn class → preview building → chọn roof → preview crane → equip. Có trạng thái loading/failed/retry cho asset; không equip thành công trước khi asset khả dụng. Trên mobile dùng paging/card, nút action một dòng và không overflow ngoài game.

Preview dựng mock tower ba body + roof tại geometry hiện tại, không chạy scored run hoặc phát achievement. Guide cảnh báo cosmetics không tăng điểm. Tên item/description có EN/VI.

- [ ] Chạy same seed/input với Default/Brick và mixed roof/crane → result/collision y hệt.
- [ ] Class compatibility, locked equip rejection, collection unlock once, retroactive milestone grant once.
- [ ] Pause/resume/locale/resize không đổi equipment active tower.
- [ ] Crop/seam bốn class, hook gắn nhà, roof footprint, city mini đọc được ở 24px.
- [ ] Lazy asset failure không boot crash, không decoder hitch lúc swing; budgets và warm-cache profile qua.
- [ ] Book/customizer/result unlock EN/VI, mobile no-scroll, keyboard/focus/ARIA.
